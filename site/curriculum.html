Zero to Data Engineer, by design.

A modular curriculum with three entry paths, a neutral conceptual core, and a deep Databricks lakehouse track — engineered backward from the ten gaps that actually stall people. Data engineering is not "writing pipelines"; it is designing reliable data products you can defend.

The Launch path

Phase by phase

Bronze → silver → gold → launch. Each phase ends in a portfolio artifact; the path ends in a governed data product.

Phase 1

Foundations

Weeks 1–13 · bronze
CLI/Git, Python, SQL, relational modeling — real-data labs from day one.
Phase 2

Core data engineering

Weeks 14–30 · silver
One running medallion pipeline → SCD2, MDM golden records, incremental, DQ.
Phase 3

Platform & production

Weeks 31–43 · gold
Unity Catalog, Lakeflow, streaming, DABs/CI-CD, PHI governance — productionized.
Phase 4

Advanced & launch

Weeks 44–50
Architecture, elective, interview prep, and your own independent capstone.
Why it's built this way

Ten gaps, closed on purpose

Mined from hundreds of real coaching calls — where people with certs and theory still stall. Every module is tagged to the gap it closes.

G1
Concept vs. application — can't explain own code or defend a tradeoff
G2
Modeling fundamentals — grain, facts/dims, reference data
G3
Incremental, CDC & history — overwrite isn't a bronze strategy
G4
Data quality & testing — schema, reconciliation, quarantine, taxonomy
G5
Streaming semantics — triggers, state, keys, composite-key dedup
G6
Dev workflow — Git → CI/CD → DABs, no manual drift
G7
Spark intuition — scale, shuffle, skew, when to tune
G8
Governance designed in, not bolted on — RBAC, masking, PII/PHI
G9
Architecture decisions — choose and defend, don't list tools
G10
Communicating the work — a narrative for interviews & stakeholders
