# Bridge placement-diagnostic datasets

Generated by `build/make_diagnostic_data.py` (deterministic). Used by the four diagnostic tasks on the Bridge page.

- **task1_sales.csv** — regional sales by rep by month (window-function practice; contains a deliberate revenue tie in East / 2024-01).
- **task2_customers.csv** + **task2_customers_api.json** — reconcile on `customer_id`. The CSV is messy (duplicate ids, mixed date formats, blank fields, money as `$1,234`); the JSON is the clean 'API'. Expect matched / csv-only / api-only / value-mismatch records.
- **task3_orders.csv** — a wide, denormalized order-line file for designing a star schema (one fact + customer/product/date dimensions).
