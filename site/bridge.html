Gambill Data Engineer Track · Path 02 — Bridge

Cross over into DE. About five months.

Bridge is for people who already work with data — analysts and software engineers — who want to become data engineers. You skip what you already own and go deep on the rest. Plan on about five months; the more the diagnostic lets you skip, the shorter it gets. A short placement diagnostic routes you to the right variant; both converge on the same lakehouse core and capstone.

Before week 1

Placement diagnostic

~30 minutes. Four short tasks decide which variant you enter, because an analyst and an SWE arrive with mirror-image strengths.

Four tasks

  1. Write a query with a window function and explain what it computes. → tests SQL depth
    Dataset task1_sales.csv — regional sales by rep by month. Rank reps within each region, or build a running monthly revenue total; there's a deliberate tie in East / 2024-01 so RANK vs ROW_NUMBER vs DENSE_RANK actually diverge.
  2. Given a messy CSV and an API, write a small Python script that loads and reconciles them. → tests Python / engineering
    CSV task2_customers.csv  ·  API task2_customers_api.json — reconcile on customer_id. The CSV is messy (duplicate ids, mixed date formats, blank fields, money as $1,234); the JSON endpoint is clean. Expect matched / CSV-only / API-only / value-mismatch records.
  3. Model a simple business process into facts & dimensions and justify the grain. → tests modeling
    Dataset task3_orders.csv — a wide, denormalized order-line file. Design a star schema (one fact + customer / product / date dimensions) and state the grain in one sentence.
  4. Walk through how you would branch, PR, test, and deploy a change. → tests dev workflow
    Learn Git Udemy — The Git & GitHub Bootcamp (Colt Steele)Coursera — Introduction to Git and GitHub (Google)DataCamp — Introduction to GitO'Reilly — Head First Git
